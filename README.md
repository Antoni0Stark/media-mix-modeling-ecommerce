# Media Mix Modeling for E-commerce Marketing

## Business Problem
Marketing teams invest across multiple paid channels but struggle to understand which channels truly drive revenue. This project uses Media Mix Modeling (MMM) to quantify the incremental impact of each marketing channel and provide budget allocation recommendations.

## Tools Used
-Python (pandas, numpy, statsmodels, scikit-learn)
-SQL (CTEs, window functions)
-Jupyter Notebook
-Data Visualization

## Key Outcomes
-Built a regression-based media mix model with lag and diminishing return effects
-Identified high-ROI and low-ROI marketing channels
-Provided data-driven budget reallocation recommendations
